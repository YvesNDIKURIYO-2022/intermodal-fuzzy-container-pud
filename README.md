## Overview

This repository contains the complete code, data, and analysis for the paper:

> **Yves Ndikuriyo** (corresponding author), **Yinggui Zhang**, **Dung Davou Fom**
> *School of Traffic and Transportation Engineering, Central South University, Changsha 410075, China*

The paper formulates the East African Corridor's cross-border intermodal
pickup-and-delivery problem as a unified fuzzy multi-objective mixed-integer
linear program, solved with an Adaptive Fuzzy Chance-Constrained Differential
Evolution (AFC-DE) algorithm. It reports a three-way comparison against a
greedy nearest-hub baseline and a deterministic-AFC-DE baseline that uses the
same metaheuristic but ignores uncertainty, and a set of sensitivity analyses
that inform recommendations for logistics operators, port authorities,
customs agencies, and EAC policymakers.

### Key Contributions

| Contribution | Description |
|---|---|
| **Integrated formulation** | A unified fuzzy multi-objective MILP that determines hub selection, spoke assignment, inter-hub transfer, pickup-and-delivery routing, and vehicle deployment under dual-source uncertainty |
| **Valuation of uncertainty modeling** | A three-way comparison that isolates the value of uncertainty modeling from the value of optimization: 22.75% cost reduction ($765,813 per planning period) relative to the deterministic baseline |
| **Actionable corridor plan** | An executable routing and fleet plan for the extended East African Corridor (2 hubs, 8 origins, 9 destinations, 6 borders), with 300 TEU of forward rail transfer and 564 vehicle-trips at 99.47% weighted utilization |

## The East African Corridor Instance

The instance is a realistic two-hub cross-border intermodal network covering
seven of the eight East African Community Partner States.

### Network Configuration

| Component | Details |
|---|---|
| **Hubs** | Mombasa, Kenya (1,000 TEU/week); Dar es Salaam, Tanzania (800 TEU/week) |
| **Origins (8)** | Nairobi (100), Nakuru (70), Arusha (50), Kisumu (60), Mwanza (65), Jinja (50), Eldoret (45), Isaka (55) — total supply 495 TEU |
| **Destinations (9)** | Kampala (120), Kigali (80), Bujumbura (50), Juba (60), Goma (40), Lubumbashi (55), Bukavu (35), Mbeya (40), Mogadishu (30) — total demand 510 TEU |
| **Borders (6)** | Malaba, Busia, Mirama Hills, Elegu, Rusumo, Liboi |
| **Vehicle types (4)** | 40-ft truck, 20-ft truck, rail wagon, lake barge |

### Fuzzy Parameter Calibration

Trapezoidal fuzzy parameters $(a, b, c, d)$ for each border crossing are
calibrated from RECTS GPS records: $b$ and $c$ at the 25th and 75th
percentiles; $a$ and $d$ at the 10th and 90th percentiles. The calibration
yields a ±15% variability band.

| Border | $a$ | $b$ | $c$ | $d$ | Mean (h) |
|---|---|---|---|---|---|
| Malaba | 10.0 | 14.0 | 22.0 | 30.0 | 18.58 |
| Busia | 4.0 | 5.5 | 9.0 | 12.0 | 7.40 |
| Mirama Hills | 3.0 | 4.5 | 7.5 | 10.0 | 6.00 |
| Elegu | 6.0 | 9.0 | 15.0 | 20.0 | 12.50 |
| Rusumo | 5.0 | 7.0 | 10.0 | 14.0 | 8.50 |
| Liboi | 2.5 | 3.5 | 5.5 | 7.5 | 4.50 |

## Method

The model is a fuzzy multi-objective mixed-integer linear program (FMOMILP)
that simultaneously determines hub selection, spoke assignment, inter-hub
transfer quantities, pickup-and-delivery routing, and vehicle deployment
under dual-source uncertainty (transit times and border clearance times).

The FMOMILP is solved with the **Adaptive Fuzzy Chance-Constrained
Differential Evolution (AFC-DE)** algorithm, which extends canonical
differential evolution with three problem-specific components:

1. **Dual-adaptive parameter control** — mutation factor $F_i$ and crossover
   rate $CR_i$ adapt per individual via jDE-2; the confidence level $\alpha$
   adapts via the 1/5 success rule.
2. **Credibility-based fuzzy Pareto dominance** — solutions are ranked using
   the credibility measure $\mathrm{Cr} = (\mathrm{Pos} + \mathrm{Nec})/2$,
   which is self-dual and yields a transitive ordering.
3. **Feasibility-aware selection** — a three-stage ranking that prioritizes
   feasible solutions, then orders them by fuzzy non-domination, then
   preserves diversity by crowding distance.

The AFC-DE is benchmarked against two baselines:

| Baseline | Purpose |
|---|---|
| Greedy nearest-hub heuristic | Isolates the value of optimization |
| Deterministic-AFC-DE | Isolates the value of uncertainty modeling |

### Algorithmic Parameters

| Parameter | Value |
|---|---|
| Population size | 25 |
| Maximum generations | 60 |
| Initial $F$ | 0.5 |
| Initial $CR$ | 0.9 |
| $\alpha$ bounds | [0.5, 1.0] |
| Learning rate $\eta$ | 0.05 |
| Archive size | 100 |
| Random seeds | 3 independent runs |

## Results

### Three-Way Comparison

| Method | Base cost (USD) | Reliability penalty (USD) | Total cost (USD) | TW violations (%) | Vehicles |
|---|---|---|---|---|---|
| Greedy nearest-hub | 2,447,746 | 22,981 | 2,470,728 | 0.90 | 549 |
| Deterministic-AFC-DE | 2,585,300 | 780,869 | 3,366,169 | 30.57 | 542 |
| **Fuzzy-AFC-DE ($\alpha = 0.75$)** | **2,600,356** | **0** | **2,600,356** | **0.00** | **577** |
| Fuzzy-AFC-DE ($\alpha = 0.95$) | 2,556,226 | 0 | 2,556,226 | 0.00 | 578 |

The fuzzy model at $\alpha = 0.75$ eliminates time-window violations
entirely and reduces total cost by **22.75% ($765,813 per planning
period)** relative to the deterministic-AFC-DE baseline. The best single-run
solution uses **564 vehicle-trips**, **300 TEU of forward inter-hub rail
transfer** on the Mombasa–Dar es Salaam link, and achieves near-perfect hub
balance (Gini coefficient 0.0017).

### Robustness and Sensitivity

| Analysis | Range tested | Key finding |
|---|---|---|
| Confidence level $\alpha$ | 0.50–0.95 | Zero TW violations across all tested levels; cost stable at ~$2.56–2.60M |
| Uncertainty level $\delta$ | 0.10–0.30 | Zero violations throughout; cost stable |
| Hub capacity | 80%–120% of nominal | Capacity not binding at current demand |
| Time-window tightness | 0.5×–1.5× | No feasible solution at 0.5×; latent flexibility at 1.25×–1.5× |

### Statistical Analysis

| Test | Statistic | Interpretation |
|---|---|---|
| Shapiro–Wilk (deterministic-AFC-DE) | $W = 0.77$, $p < 0.05$ | Non-normal |
| Shapiro–Wilk (fuzzy $\alpha = 0.75$) | $W = 1.0000$, $p = 1.0000$ | Identical runs |
| Wilcoxon signed-rank | statistic = 0.0000, $p = 0.0625$ | Power-limited (3 runs) |
| Cohen's $d$ | 1.3278 | Large effect |
| Friedman (across $\alpha$) | statistic = 2.0000, $p = 0.3679$ | No difference |

The Wilcoxon $p$-value of 0.0625 is the most extreme value attainable with
three paired runs and therefore cannot reach the 5% threshold regardless of
effect magnitude; the large effect size ($d = 1.3278$) supplies the primary
evidence of practical significance.

## Installation

```bash
# Clone the repository
git clone https://github.com/YvesNDIKURIYO-2022/intermodal-fuzzy-container-pud.git
cd intermodal-fuzzy-container-pud

# Create a virtual environment (optional but recommended)
python -m venv .venv
source .venv/bin/activate         # Linux/macOS
# .venv\Scripts\activate          # Windows

# Install dependencies
pip install -r requirements.txt
```

## Usage

```bash
# Reproduce all tables, figures, and the JSON output
python afc_de.py

# Use a custom output directory
python afc_de.py --output-dir ./my_results

# Light mode (smaller sensitivity grid, for laptops)
python afc_de.py --light

# Reproducibility check with a different seed
python afc_de.py --seed 123
```

The script is deterministic given `--seed` (default 42) and reproduces every
number in the manuscript's Section 5.
